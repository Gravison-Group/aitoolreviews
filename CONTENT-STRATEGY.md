## Article Type Mix (target %)
- Individual tool reviews: **35%**
- Buying guides / best-of lists: **25%**
- Comparison articles (X vs Y): **20%**
- How-to / workflow guides: **10%**
- "AI for [use case/persona]" guides: **10%**
- News/release coverage: **0%** *(avoid — becomes stale immediately)*
- pSEO programmatic: **0%** *(not applicable)*

**Rationale:** The site is over-indexed on buying guides and generic "how to use AI writing" content. Individual tool reviews are where the traffic is, and they are massively underrepresented given the number of major tools without dedicated pages.

---

## Avoid List

- **Expense management software** (Expensify, QuickBooks expense features) — already exists but is off-brand; do not replicate; these articles should be sunset or redirected
- **Stripe dunning / billing tools** — off-brand; not AI tools; do not replicate
- **OpenClaw review** — conflicts of interest; remove or heavily caveat if kept
- **News/announcement articles** ("OpenAI announces X") — stale within days, no evergreen value, low RPM
- **"How to use ChatGPT to write [X]" prompt tutorials** — over-saturated; only worthwhile if genuinely differentiated
- **Generic productivity apps without strong AI component** (Trello, Asana, Basecamp) — off-brand
- **AI "get rich quick" / side hustle content** (e.g., "make money with AI writing") — low-quality signal, high bounce rate, low RPM advertisers
- **Enterprise/B2B tools** requiring demo calls to evaluate (Salesforce Einstein, etc.) — can't create authentic reviews without access
- **AI tools not yet publicly available** — speculative content ages badly

## Affiliate/Monetization Priorities

**Display ads (primary):** RPM depends on traffic volume and topic. AI tool content targets well-funded advertisers. Prioritize articles that attract buying-intent searches (reviews, comparisons, best-of).

**SaaS affiliate programs (secondary):**
- **Jasper AI:** $29–$125/month SaaS, typically 30% recurring commission
- **Writesonic:** Similar structure
- **Surfer SEO:** $49–$199/month, affiliate program available
- **Frase.io:** Affiliate program; $45–$115/month
- **Cursor:** Check for affiliate/referral program
- **Notion AI:** Referral program
- **Runway:** Check affiliate program

**Program notes:**
- Impact.com and ShareASale host many AI SaaS affiliate programs — worth checking both for any tool being reviewed
- Amazon Associates not useful here (no physical products)
- Prioritize tools with recurring monthly commissions over one-time payouts

## Content Intelligence Filter Rules

```
CLUSTER ASSIGNMENT
- IF topic is a review of a specific named AI tool → assign to Tool Review cluster
- IF topic is "best AI [category] tools" or "top [category] AI tools" → assign to Buying Guide cluster
- IF topic is "[tool A] vs [tool B]" → assign to Comparison cluster
- IF topic is "how to use [AI tool] for [task]" → assign to Workflow/How-to cluster
- IF topic is "[AI tool] for [type of user/persona]" → assign to Use-Case Guide cluster

PRIORITIZATION RULES
- IF topic = standalone review of a major AI tool (ChatGPT, Claude, Gemini, Midjourney, Cursor, GitHub Copilot) AND no dedicated review page exists → PRIORITY: CRITICAL
- IF topic = review of any AI tool AND no page exists for that tool → PRIORITY: HIGH
- IF topic = AI image generator OR AI coding tool AND site has fewer than 4 articles in that cluster → PRIORITY: HIGH (underdeveloped clusters)
- IF topic = comparison article AND both tools have dedicated review pages → PRIORITY: HIGH (review pages must exist first)
- IF topic = "best AI [category]" AND that buying guide already exists → PRIORITY: LOW (update existing instead)
- IF topic = AI writing tool (any form) AND more than 8 AI writing articles already exist → PRIORITY: LOW (cluster is saturated on this site; only accept if genuinely differentiated)

FRESHNESS RULES
- IF article title includes a year (e.g., "2025") AND year is outdated → FLAG as update candidate, do not create new article
- IF topic is about an AI tool that released a major new version in the last 3 months AND existing review does not mention it → FLAG existing review for update
- IF topic is a breaking news/announcement article ("X company announces Y") → SKIP (no evergreen value)
- AI tool review articles should be treated as evergreen with annual update cycles; do not create a "2026" and a separate "2027" article — update in place

QUALITY / BRAND GATES
- IF topic is about expense management, dunning, billing, or accounting software WITHOUT strong AI component → SKIP (off-brand)
- IF topic requires hands-on access to a tool that is not publicly available → SKIP
- IF topic could require medical, legal, or financial advice claims → FLAG FOR HUMAN REVIEW
- IF topic overlaps >60% with an existing article slug or title → SKIP (do not create near-duplicates; update existing instead)
- IF topic is "how to make money with AI" style → SKIP (low RPM, off-brand signal)
- IF topic is about AI writing without a clear differentiated angle vs existing articles → SKIP (cluster is saturated)

AFFILIATE VALIDATION
- IF topic is a tool review → CHECK if tool has affiliate program on Impact, ShareASale, or direct → note affiliate availability in article brief
- IF tool has recurring commission > 20% → tag as HIGH MONETIZATION VALUE → elevate in queue

COMPETITOR FRESHNESS CHECK
- IF topic is a major tool review (ChatGPT, Midjourney, etc.) → assume high competition → article must have a current-year publish date AND reference the most recent version/model to be competitive
```
