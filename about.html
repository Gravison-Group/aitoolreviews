Methodology

How We Test & Score AI Tools

Every review follows the same structured process. Here's exactly how we evaluate each tool.

01
Hands-On Testing
We use every tool for real tasks over a minimum of one week. No shortcuts. We test writing, coding, reasoning, research, and any tool-specific capabilities.
02
Standardized Benchmarks
We run every tool through the same set of benchmark prompts covering: creative writing, factual accuracy, reasoning puzzles, code generation, and document summarization.
03
Scoring Rubric
Each category is scored 1–5 on consistent criteria. Overall scores are weighted averages, not gut feelings. We show our sub-scores so you can decide what matters most for your use case.
04
Pricing Verification
We check pricing directly from each company's pricing page at time of publication. AI pricing changes often — we include the last-updated date on every review.
05
Peer Review
Each review is checked against community consensus, independent benchmarks (MMLU, HumanEval, etc.), and public user feedback to ensure we're not outliers.
06
Ongoing Updates
We re-test whenever a major update ships. AI models improve fast — a review from 6 months ago can be dangerously outdated. Every review shows its last-updated date.
Scoring

What Our Scores Mean

5.0
Exceptional

Best in class. Sets the standard for its category. Minor flaws don't detract from an otherwise outstanding tool.

4.0–4.9
Excellent

Strong recommendation. Delivers real value, performs reliably, with only minor limitations.

3.0–3.9
Good

Solid tool with meaningful limitations. Worth considering for specific use cases.

2.0–2.9
Below Average

Significant problems. Only recommended if you have a very specific, niche use case.

We score five dimensions for most AI assistants: Writing Quality, Coding, Reasoning, Value for Money, and Ease of Use. For specialized tools like image generators, we adapt the dimensions to fit the tool's purpose.
